# 复盘表模板

每篇发布 48 小时后填一次。结论以自有数据裁决，阈值只是初筛标尺。

| 指标 | 数值 | 阈值/标尺 | 诊断 |
|---|---|---|---|
| 标题 | | ≤20 字 | |
| 点击率 | | <6% → 改封面标题 | |
| 图文停留时长 | | <30s → 改开头与干货密度 | |
| 收藏率 | | <3% → 改选题结构 | |
| 搜索流量占比 | | <30% → 改 SEO（标题/首段/标签同一关键词组） | |
| 藏赞比（收藏/点赞） | | 持续 >2 → 改写法（防"阿司匹林收藏"） | |
| 评论数/质量 | | | |

## 诊断写法示例

- 点击率 4.2%（<6%）：封面标题钩子弱，下次把 DDL 提前到标题前 8 字。
- 停留 22s（<30s）：开头 3 行没进技巧，钩子后加了废话。
- 收藏率 5.1%（≥3% 达标）：3 个提示词"复制即用"起了作用，保留。
- 搜索占比 41%（≥30% 达标）：标题/首段/标签同一词组"AI预习"生效。
- 藏赞比 2.6（>2 警告）：结尾缺"当场能用"的行动指令，下次补。

## 复盘纪律

1. 一次只改一个变量（这周改封面，就别同时改发布时间）。
2. 阈值是机构口径 + 自有数据双标尺：先贴标签，再看数据是否支持。
3. 有效结论写回选题库 / 文案规范，变成下一轮的输入。
