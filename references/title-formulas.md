# 七类标题公式（含真实案例）

每类给 3 个可替换模板 + 1 个真实发布案例。所有案例标题 ≤20 字，均来自同一账号实战。

## 1. 痛点型——命中具体问题

- 「{场景}乱糟糟？AI{动作}3招」
- 「{任务}总{痛点}？AI帮你{结果}」
- 「{人群}{痛点}？试试这3招」

案例：《大学生笔记乱糟糟？AI变导图3招》（2026-10-17 发布）

## 2. 数字型——制造清晰感

- 「{DDL}？AI{动作}{数字}招」
- 「{数字}分钟{任务}？AI压成{数字}分钟」
- 「{数字}天后{事件}？AI{动作}」

案例：《期中剩5天？AI抓考点3招》（2026-10-28）、《40分钟网课？AI压成5分钟速读》（2026-10-31）

## 3. 对比型——凸显变化

- 「{旧方式}{痛点}？AI{新方式}」
- 「还在{笨办法}？AI{数字}步搞定」
- 「{任务}前后：{旧} vs {新}」

案例：《40分钟网课？AI压成5分钟速读》——40 分钟 vs 5 分钟的对比即钩子。

## 4. 稀缺型——制造注意力

- 「{DDL}！{人群}抓紧看」
- 「{事件}前夜：{动作}」
- 「最后{数字}天，{任务}这样收尾」

案例：《面试还有3天？AI陪练自我介绍》（2026-10-30）——"还有3天"既是 DDL 钩子也是稀缺。

## 5. 共鸣型——建立信任

- 「{人群}都懂：{痛点}」
- 「第{数字}次{失败经历}后，我换了打法」
- 「没人告诉你的{真相}」

用法：教程号慎用，共鸣型更适合复盘帖；用时必须配真实细节，空泛共鸣等于鸡汤。

## 6. 资源型——提高收藏

- 「{任务}提示词：复制即用」
- 「{数字}个{工具/模板}，{人群}自取」
- 「{场景}万能提示词」

要点：资源必须真的"复制即用"，正文里给出完整提示词原文，缺这一步收藏率起不来。

## 7. 反常识型——制造转发理由

- 「别再{常见做法}了，{反常识做法}」
- 「{任务}不需要{常见误区}」
- 「{数字}秒就够：{反常识结论}」

案例：《面试还有3天？AI陪练自我介绍》正文技巧一"先缩成30秒，别背长文"——反常识点：自我介绍不是背得越长越好。

## 硬检（每条标题必过）

1. ≤20 个中文字符
2. 至少 2 个张力元素（DDL / 数字 / 对比 / 身份 / 悬念）
3. 不把答案说完（留悬念进正文）
4. 用更大的用户词（"大学生"比"高校学生"好）
5. 击中真实痛点（能说出具体场景才算）
