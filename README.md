# xhs-ai-ops

小红书 AI 教程账号全链路运营 Skill：选题（含学术红线）→ 文案 → 图文卡片 → 发布 → 数据复盘 → 每日学习沉淀。

这不是通用方法论，而是一套从真实账号跑出来的可执行规范：Agent 照此可独立运营一个垂类账号，人类只处理登录等机器做不了的环节。

## 包含内容

- `SKILL.md` — 全链路运营规范（7 章）
- `CHANGELOG.md` — 每日学习沉淀的变更记录

## 核心设计

- **学术红线**：AI 是否在替学生产出要交上去/要上台讲的学术成品——是，即毙。两次被平台判「扰乱管理秩序」换来的教训，优先级高于一切增长目标。
- **搜索优先**：垂类教程号吃搜索长尾，不追热点；标题/首段/标签共用同一关键词组。
- **自己进化**：每天学习沉淀，稳定结论反写回 SKILL.md。

## 安装

```bash
# Claude Code / Codex 等支持 Skills 的 Agent
npx skills add https://github.com/xiaoxiehang/xhs-ai-ops
```

或把 `SKILL.md` 放到你的 skills 目录即可。
